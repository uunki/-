# Практичне заняття 13 — Командний інтерфейс додатка

## Тема
Консольна текстова гра з каталогом персонажів.

## Запуск
Потрібен Python 3.10 або новіший. Зовнішні бібліотеки не потрібні.

```bash
python main.py
```

## Команди
| Команда | Призначення |
|---|---|
| `help` | список команд |
| `characters` | список персонажів |
| `refresh` | повторне завантаження каталогу |
| `add` | створення персонажа через діалог |
| `start` | почати гру та обрати персонажа |
| `attack` | атакувати ворога |
| `defend` | виконати захисну дію |
| `status` | показати стан гри |
| `save` | зберегти гру |
| `load` | завантажити збереження |
| `exit` | вихід |

Дані персонажів і збереження створюються автоматично в каталозі `data/`.
